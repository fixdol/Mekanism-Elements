⚡ Mekanism: Elements — Changelog

🚀 [3.0.16]

Additions & Changes
1) Guide Book

Patchouli is now a required dependency and the mod ships a full in game guide, generated by datagen.
The book has five categories (Machines, Materials, Chemicals, Medicine, Building) and a page for every single machine, block and item the mod registers, built by walking the item registry so nothing can be missed.
Machine entries carry their in game description plus a crafting page; item pages are spotlights linked to their recipe.
The book has its own artwork rather than a recoloured Patchouli skin: an industrial steel shell with hazard banding, technical grid pages with a radiation trefoil watermark, and a green lit spine. The book item is a steel bound logbook with a radioactive badge.
It is craftable, and also sits at the end of the Mekanism: Elements creative tab.
Translated into all eight languages the mod supports.
2) Internal

Updated to NeoForge 21.1.240.
Migrated the build from NeoGradle to ModDevGradle 2.0.146.

🚀 [3.0.15]

Additions & Changes
1) Chemical Demolition Machine

New texture, redrawn in the Mekanism style instead of reusing the Adsorption Separator's one.
Steel casing with beveled panels, chemical sight glasses on both tanks, hazard striping on the adsorbent core and a status light on the front panel. The I/O ports keep Mekanism's own port sprites.
2) Infinity Ore Reprocessing

Rebuilt as a normal single block machine. The old 3x3x3 Blockbench structure and the baked model that repositioned it are gone; the block is now a plain cube model with its own front, back, side, top and bottom faces, plus a lit front for the active state.
New textures drawn from a neutral steel palette blended from the Enrichment Chamber (light top plate), the Crusher (dark recesses) and the Seawater Pump / Adsorption Separator (mid body tones), with a seawater coloured viewport and status LEDs that light up while the machine runs.
3) Internal

Every blockstate, model, tag and data file is now produced by datagen. src/main/resources holds only textures, sounds and mod metadata.
New providers: MSBlockStateProvider, MSItemModelProvider, MSMachineModels, MSFluidTagsProvider, MSItemTagsProvider and ChemLibRecipeProvider.
The hand made Blockbench machine models were converted to the model builder API and verified to round trip identically (89 elements and 502 faces, matching UVs, rotations, cullfaces and emissivity).
The Blockbench source file was moved out of the resources folder so it no longer ships inside the jar.
4) Fixes that came out of the datagen migration

The c:potassium_hydroxide fluid tag listed mekanismelements:potassium_chloride instead of the hydroxide.
The c fluid tags, the create no_infinite_draining tag and the ChemLib crystallizing recipes sat in pre 1.21 folder names (tags/fluids and recipes instead of tags/fluid and recipe), so none of those 32 files were being loaded at all. Datagen now writes them to the 1.21 paths.
The ChemLib recipes are now guarded by a neoforge:mod_loaded condition so they no longer error when ChemLib is absent.
Aqua High-Quality Concrete Slab used minecraft:block/slab as its top model parent instead of minecraft:block/slab_top, so the top slab rendered in the bottom half.
White High-Quality Concrete Stairs pointed at the plain (gray) stairs model in the facing=south, shape=outer_right variant.

🚀 [3.0.14]

Bug Fixes
1) Chemical Demolition Machine

The second output slot was never registered in the item side configuration, so pipes, Logistical Sorters and auto-eject could only ever pull from the first one and the second output had to be taken out by hand.
Both output slots are now part of the OUTPUT and INPUT_OUTPUT side configuration, so automation can extract both results.
